# Quality check: 10 engineering rules (2026-11-01)

Scope: the Java (`java/`), CPython (`python/`) and Node.js (`js/`) harnesses, the shared spec and
the Python runner/log reader. Windows 11, Temurin 21.0.12.1, CPython 3.14.5, Node.js 24.19.0.

| # | Rule | Status | Evidence |
|---|---|---|---|
| 1 | Every call can fail | pass | Child processes run with a timeout and a non-zero exit raises with the stderr tail (`compare.py` `_run`). No network calls. Every `catch` returns exit 2 with the message (`js/src/cli.js:62`, `escape-probe.js:100`, Java `ChurnMain`/`EscapeMain`/`Args`); no empty catch. |
| 2 | Writes safe to retry | pass | The runner overwrites its result files (`churn.jsonl`, `churn.md`, `escape.*`) from scratch on every run; a rerun gives the same files. Nothing appends. |
| 3 | No race conditions | N/A | Each measurement is a separate process run one after another; no shared mutable state. |
| 4 | Don't trust the clock | pass | Durations use `perf_counter_ns` (Python), `System.nanoTime` (Java) and `process.hrtime.bigint()` (Node, `js/src/meter.js:19`); no wall-clock deltas or stored timestamps. |
| 5 | Read before changing | pass | The runner sets only `TMP`/`TEMP`/`TMPDIR` for the JIT-log JVM and `PYTHONDONTWRITEBYTECODE`; no undocumented variables are read. |
| 6 | Never break compatibility | pass | Result-line formats are pinned by the parsers and `spec/workload.json` (version 1); unchanged. |
| 7 | One source of truth | pass | Checksums live only in `spec/workload.json` and every runtime's tests read it. |
| 8 | Small changes, no secrets, validate input | pass | No secrets. CLI options bounded in all three harnesses; result lines size-capped, exact fields and types; LogCompilation files size-capped and DTD/ENTITY declarations refused. |
| 9 | Tests that can fail | fixed | No skips or tautologies. 10 hand mutants across the three runtimes: 8 killed before, 10 after. |
| 10 | Re-verify | pass | Results below. |

## Mutation check

(script in the git-ignored `.tmp/`).
